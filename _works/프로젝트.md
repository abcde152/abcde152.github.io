  text: "<p>최근 개인 정보 유출 및 통신 감청의 위협이 증가함에 따라, 안전한 소통 환경의 중요성이 부각되고 있습니다. 본 <b>채팅 암호화 프로젝트</b>는 사용자들이 안심하고 메시지를 주고받을 수 있는 보안 강화된 웹 기반 채팅 시스템을 구축하는 것을 목표로 하였습니다. 특히, 평문으로 전송되는 메시지가 탈취될 경우 발생할 수 있는 잠재적 위험을 인지하고, 이를 방지하기 위한 강력한 암호화 메커니즘 도입에 집중했습니다.</p>
  <p>주요 목표는 다음과 같습니다:</p>
  <ul>
    <li>사용자 친화적인 <b>HTML 기반의 웹 인터페이스</b> 개발.</li>
    <li>안정적인 <b>MySQL 데이터베이스</b>를 활용한 채팅 기록 및 사용자 정보 관리.</li>
    <li>메시지 전송 시 <b>RSA 공개키 암호화 방식</b>을 적용하여 통신 과정의 기밀성 확보.</li>
    <li>개발 환경으로 <b>Visual Studio Code (VSCode)</b>를 활용하여 효율적인 코드 작성 및 디버깅 수행.</li>
  </ul>
  <p>궁극적으로 이 프로젝트를 통해 웹 보안, 데이터베이스 관리, 그리고 핵심적인 암호화 알고리즘의 실제 적용 능력을 향상시키고자 했습니다.</p>"

description2:
  title: 주요 기능 및 구현 성과
  text: "<p>본 채팅 암호화 프로젝트는 다음과 같은 주요 기능과 기술적 성과를 달성했습니다:</p>
  <ul>
    <li><b>보안 채팅 기능:</b> 모든 채팅 메시지는 전송 전에 RSA 알고리즘을 사용하여 암호화되며, 수신 측에서만 복호화가 가능하도록 구현하여 중간자 공격(Man-in-the-Middle Attack)으로부터 메시지의 기밀성을 보호합니다.</li>
    <li><b>사용자 인증 및 관리:</b> 사용자 등록, 로그인, 로그아웃 기능을 구현하여 접근 제어를 강화하고, 각 사용자에게 고유한 공개/개인 키 쌍을 할당하여 안전한 통신을 보장합니다.</li>
    <li><b>실시간 채팅 (선택 사항 - 만약 구현했다면):</b> 웹소켓(WebSocket) 또는 AJAX 폴링 방식을 활용하여 실시간에 가까운 메시지 전송 및 수신 환경을 구축했습니다.</li>
    <li><b>데이터베이스 연동:</b> MySQL을 사용하여 사용자 계정 정보, 채팅 메시지(암호화된 형태로 저장), 공개키 등을 효율적으로 관리하고, 데이터 무결성을 유지했습니다.</li>
    <li><b>직관적인 UI/UX:</b> HTML, CSS, JavaScript를 활용하여 사용자 친화적이고 반응형(responsive)인 웹 인터페이스를 설계하여 어떤 디바이스에서도 편리하게 이용할 수 있도록 했습니다.</li>
  </ul>
  <p>이 프로젝트를 통해 <b>RSA 암호화 알고리즘의 동작 원리와 실제 적용 방법</b>에 대한 깊이 있는 이해를 얻었으며, <b>풀스택 웹 개발 과정에서의 보안 고려 사항</b>을 체득할 수 있었습니다. 특히, 프론트엔드와 백엔드 간의 안전한 데이터 통신 흐름을 설계하고 구현하는 과정에서 문제 해결 능력과 실무 역량을 크게 향상시킬 수 있었습니다.</p>"
