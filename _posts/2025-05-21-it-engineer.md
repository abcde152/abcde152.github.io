# 정보처리산업기사 자격증 취득 전략

정보처리산업기사는 소프트웨어, DB, 시스템 설계 등 정보기술 전반의 지식을 평가하는 **국가기술자격증**입니다. IT 직군 취업 시 매우 유리합니다.

---

## ✅ 학습 로드맵

- **1단계**: 프로그래밍 언어와 운영체제 개념 정리  
- **2단계**: 데이터베이스 설계 / 정규화 / SQL  
- **3단계**: 시스템 개발 및 관리 개념  
- **4단계**: 기출 문제 반복 풀이 및 서술형 연습

---

## 📚 추천 자료

- 교재: 길벗 정보처리산업기사, 이기적 시리즈  
- 사이트: 큐넷(Q-net), 기출 공유 블로그  
- 실습: Python / SQL 실습 추천

---

## 💡 실기 팁

- 서술형은 **암기 + 키워드 조합**으로 연습  
- 시스템 생명주기(SDLC), 소프트웨어 공학 파트는 자주 출제  
- DB 문제는 실습해보는 것이 이해에 좋음

---

## ✅ 공부 플랜 예시 (5주)

| 주차 | 내용                               |
|------|------------------------------------|
| 1주차 | 운영체제 / 프로그래밍 언어 이론 정리   |
| 2주차 | DB 설계, 정규화, SQL 실습             |
| 3주차 | 시스템 분석/설계, 소프트웨어공학 이론   |
| 4주차 | 필기 + 실기 기출문제 풀이             |
| 5주차 | 서술형 작성 연습 + 오답노트 정리        |

---

> 다음 글에서는 **서술형 실기 문제에서 자주 나오는 핵심 키워드 요약**을 정리합니다.
